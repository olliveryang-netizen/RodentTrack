# Changelog

## [1.0.0] – 2026-11-16
First public release.

- Point-and-click setup window: arena (4 corners, perspective-corrected), round/square objects, wire cages, glare exclusion zones
- One-click automatic threshold; live detection preview on any frame
- Measures: distance, speed, centre time/entries, immobility, per-zone exploration time, bouts, first-contact latency, mean bout, climbing time, discrimination index (DI)
- Nose/tail orientation: exploration = nose inside the contact zone while the body is not on the object
- Time bins, trajectory plot, heat map, annotated video, batch analysis with one summary table
- Chinese and English interface and result files (`--lang zh|en`, language box in the main window)
- One-double-click launchers for Windows, macOS and Linux
- Synthetic demo videos with ground truth, validation script and automated tests (Windows/macOS/Linux)
